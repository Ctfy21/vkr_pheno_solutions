Весь путь данных в одной системе

Обычно снимки лежат в папках, показания датчиков остаются в камере, а замеры в таблицах. PhenoPlant собирает их в одном месте и связывает между собой: каждый признак растения хранится вместе со снимком и условиями, в которых его получили.

  1. Климатические камеры

    Камера передаёт по API показания датчиков: температуру, влажность, освещённость и CO₂.

  2. Массовая загрузка снимков

    Файлы сопоставляются с растениями по имени, время съёмки берётся из EXIF с часовым поясом, для каждого файла считается SHA-256.

  3. Решения ИИ и компьютерного зрения

    Исследователь выбирает метод фенотипирования из реестра, и анализ запускается в отдельном контейнере.

  4. Признаки и стадии

    Высота, площадь листьев, стадия развития и другие признаки сохраняются как переменные CropOntology рядом с условиями камеры в момент съёмки.

  5. Графики, статистика, протоколы

    Протокол опыта задаёт растения, варианты и измеряемые признаки. Система считает среднее, SD, CV и t-критерий Уэлча по датам, строит графики и выгружает отчёты PDF и XLSX.

  6. Цифровой двойник

    Модель роста на рядах «снимки, признаки, климат» прогнозирует развитие растения при других условиях.

Метод вашей лаборатории

Собственный алгоритм упаковывается в контейнер и добавляется в реестр через веб-интерфейс или API.

Климатические камеры по API

Камера передаёт в систему показания своих датчиков. Каждый снимок автоматически связывается с ближайшими показаниями камеры, поэтому признаки растения всегда видны вместе с условиями, в которых оно росло.

  • Реестр камер с датчиками температуры, влажности, освещённости и CO₂.
  • Для снимка берутся показания в окне ±30 минут от времени съёмки.
  • Протокол не привязан к производителю: показания может отправлять контроллер камеры или промежуточный скрипт.

API для камер

POST /api/sensor-readings

Камера отправляет показания датчиков: температуру, влажность, освещённость, CO₂.

GET /api/images/{id}/environment

Условия камеры в момент съёмки конкретного снимка.

Цифровой двойник растения

Ключевая инновация проекта — приближение к цифровым двойникам растений: модели, которые воспроизводят развитие растения в виртуальной среде на основе реальных данных. Это позволит прогнозировать рост при изменении климатических условий и оптимизировать сценарии экспериментов.

  1. Реальные данные

    Ряды снимков, признаков и показаний климата по каждому растению. Система собирает их уже сейчас.

  2. Модель роста

    Обучается на этих рядах и воспроизводит развитие растения в виртуальной среде.

  3. Прогноз и сценарии

    Как изменится рост при другой температуре, влажности или освещённости и какие условия опыта стоит проверить.

Переменные CropOntology

Каждая переменная задана тройкой «признак, метод, шкала», поэтому результаты разных решений можно сравнивать.

Открытый API

Загрузка снимков, показания датчиков, запуск анализа и выгрузка результатов доступны по HTTP.

Docker и Kubernetes

Каждое решение работает в своём контейнере как задание Kubernetes; платформа разворачивается на MicroK8s.

Keycloak и роли

Вход через Keycloak (OIDC), роли администратора, исследователя и наблюдателя; права проверяются на сервере.

Облако или свой сервер

SaaS или установка в изолированном контуре организации. Снимки хранятся в GridFS с контрольной суммой SHA-256 и выдаются по подписанным ссылкам.
